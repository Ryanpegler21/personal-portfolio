# Ryan Pegler — Personal Portfolio

A responsive, dependency-free portfolio for [ryanpegler.com](https://www.ryanpegler.com/).

## Files

- `index.html` — portfolio content and metadata
- `styles.css` — responsive layout, light/dark themes, project artwork, and motion
- `script.js` — theme preference, navigation, scroll reveals, and typing animation
- `assets/portrait.jpg` — existing Ryan Pegler portrait, now hosted with the site
- `assets/favicon.svg` — portfolio favicon

Serve the repository root with any static host. No install or build step is required. For local development, run `python3 -m http.server 8000` and open `http://localhost:8000`.

## Content maintenance

Experience and education are current as of October 2026. Allstate is listed as Financial Data Analyst, Reporting & Automation / 360° Finance (July 2026–present). Illinois reflects graduation in May 2026; Bocconi is an exchange semester, not a degree program. Project descriptions avoid unverified adoption or model-accuracy claims.

Contact links open email or LinkedIn directly; there is no simulated contact form. The existing `Ryan_Pegler_Resume.pdf` is retained for continuity but is not linked in the new page because its content has not been updated.

The site respects `prefers-reduced-motion`. Page content remains readable if JavaScript is unavailable. Fonts load from Google Fonts with system fallbacks. Project illustrations are decorative CSS artwork, not product screenshots.

## Deployment

Publish the repository root using the existing hosting integration. Changes on `main` can trigger deployment if the connected host is configured to do so. No hosting configuration, domain settings, or external services were changed by this redesign.
